## About

I build AI systems end to end: choosing and fine-tuning the model, testing it against a real benchmark, then wrapping it in an application people can actually use.

I care most about systems that run on infrastructure the user controls. Privacy and deployability shape most of my design decisions, which is why much of my work runs on local models.

<br/>

## Selected work

**01** &nbsp; **[Qwen3-ExpertTools](https://github.com/MadhuryaPasan/Qwen3-ExpertTools)**
Fine-tunes Qwen3 1.7B for function calling and structured output. Evaluated on the Berkeley Function Calling Leaderboard and packaged as GGUF for Ollama.
<sub>Unsloth · QLoRA · BFCL · GGUF · Ollama</sub>

**02** &nbsp; **[Smart Campus Hub](https://github.com/MadhuryaPasan/Smart-Campus-Hub)**
A full-stack campus resource management platform with an on-premise AI assistant that guides users through workflows.
<sub>Next.js · Spring Boot · LangGraph · Docker</sub>

**03** &nbsp; **[Local RAG System](https://github.com/MadhuryaPasan/Local-RAG-System)**
Privacy-first PDF analysis using locally hosted LLMs, so documents stay on the user's own machine.
<sub>FastAPI · LangChain · Ollama · Docker</sub>

**04** &nbsp; **[Personal Finance Advisor](https://github.com/MadhuryaPasan/Personal-Finance-Advisor)**
A local AI finance application covering transaction categorisation and budgeting, plus an experiment with a fine-tuned finance model.
<sub>Streamlit · spaCy · Gemma · FastAPI</sub>
